The Daily Challenge is the Problem of the Day (POTD) scheduled for a UTC challenge day. It is a normal problem workspace with additional progress context—not a different editor or an automatic daily submission.

## Participate

1. Find the **Daily Challenge** card in the product surface that presents it.
2. Open **Solve today’s challenge** to enter that problem’s workspace.
3. Submit an accepted Java solution through the normal official Submit workflow.
4. When the returned submission identifies a newly completed daily challenge, the workspace shows a completion dialog with the current streak.

The card shows the challenge date and a client-side display of the next reset time. The product labels the challenge day as UTC.

## What counts toward a streak

An accepted submission must match the scheduled Daily Challenge on its challenge date to count. Running code, saving it in Playground, or accepting another question does not satisfy that Daily Challenge completion rule.

The profile can show current streak, longest streak, total POTD completions, and a reminder whether today’s challenge is already solved. These are progress views; a zero, missing, or still-loading value should not be read as a promise that scheduling itself failed.

## Scheduling boundaries

The UI can explicitly show **No challenge is scheduled for today yet. Check back soon.** That is a supported visible state, not a request to choose a random replacement question. The documentation does not promise a challenge for every day or a particular curation schedule.

## Limits and recovery

- The streak is based on accepted official submissions, not a Run result.
- Date boundaries are UTC for the challenge, even if your browser displays a localized reset countdown.
- If daily progress does not refresh after a result, revisit the profile or submission after the submission reaches its terminal state; do not assume a separate schedule was created by the client.
