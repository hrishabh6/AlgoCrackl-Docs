## Purpose

AlgoCrack is composed from independent repositories. This page is the public source entry point for engineering documentation: it links claims to the exact RC.8 source revision without making the documentation build contact GitHub.

Each public link was checked against the configured repository remote on 2026-10-25. The older Kustomize repository is intentionally shown as unavailable because anonymous GitHub access was not verified; it is historical deployment material, not the current Helm contract.

## How to use these links

- **View repository** opens the verified public repository home.
- **View pinned revision** opens the full RC.8 commit, rather than the moving default branch.
- **Implementation source** links a relevant file or directory at that same commit where one is suitable for architectural orientation.

The table is not a claim that every commit was deployed to a particular running workload. The [RC.8 release](/docs/releases/v1.0.0-rc.8) page records the published image/source manifest; the global architecture pages explain the separate missing revision-19 deployment snapshot.
