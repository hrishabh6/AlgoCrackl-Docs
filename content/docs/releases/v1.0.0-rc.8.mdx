`v1.0.0-rc.8` is the documentation baseline. Eight `linux/amd64` images are published and recorded as `VERIFIED`. The release runs on a local Kubernetes cluster from those images. It is a personal production-style environment.

Image identity is the tag plus the manifest digest below. A rebuild of the same Git commit produces a different digest, so this page does not treat a commit SHA as a substitute for the published digest.

## Deployment-evidence note

The project owner reported a successful Helm revision **19** deployment on 2026-10-25. That report is distinct from the published RC.8 image manifest: `images.tsv` verifies the source/image mapping, while a checked-in revision-19 values/manifest export and workload image-ID capture are still absent from the documentation evidence set. The source pins on this page therefore remain RC.8 release pins, and deployment-sensitive architecture pages remain source-qualified rather than being silently promoted to **Verified deployed**.

## Execution contract

| Mode | RC.8 route |
| --- | --- |

| Java Playground | Persistent NsJail runner |

| Kubernetes Job and local process | Still in source. Not the selected route for the two rows above. |

## Limits that travel with this release

- Playground execution is Java-only.
- Compile output may include a `JAVA_TOOL_OPTIONS` banner. That banner is the runner's JVM flag, not a line of the user's program.
- The submission language enum names C++ and JavaScript. Naming them is not the same as executing them on this release.
- Do not read this page as a capacity, traffic, or uptime statement.
