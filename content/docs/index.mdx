AlgoCrack is a personal LeetCode-style coding platform. You browse problems, write code, run it against tests, and submit a solution. The RC.8 release packages that system as eight published container images and runs it on a local Kubernetes cluster.

This site documents that release. It does not describe a public multi-tenant service, and it does not report traffic, user counts, or uptime.

## Start using AlgoCrack

Follow the task-oriented guides to [get started](/docs/using/getting-started), [find problems](/docs/using/problem-discovery), [use the editor](/docs/using/editor-and-focus), and learn the difference between [Run and Submit](/docs/using/run-and-submit). The [Playground guide](/docs/using/playground) covers standalone Java programs; the [support matrix](/docs/using/features) distinguishes verified execution from saved or retained language options.

## What you can do

- Sign in with a local account or Google OAuth.
- Browse the problem catalogue, tags, saved problems, and custom lists.
- Run a solution against visible tests, including cases you type, and submit it for judging.
- Use Playground to run a Java snippet that is not attached to a problem.
- Follow a scheduled Problem of the Day, a profile, rank, and badges.

Java is the language RC.8 actually executes for both submissions and Playground. The [support matrix](/docs/using/features) separates that from languages that can be named or saved but are not a verified execution path.

## What this release is made of

The browser talks to an ingress. Page routes stay on the Next.js frontend. API routes pass through a ModSecurity edge, then an internal API gateway, then Auth, Problem, and Submission services. MySQL holds application data. Submission Service asks the Code Execution Engine to run code. The engine places work on Redis, and a separate Java runner executes it inside NsJail.

The [architecture overview](/docs/architecture/overview) is the map. The [repository map](/docs/architecture/repositories) says which Git repository produced each image. The [RC.8 release](/docs/releases/v1.0.0-rc.8) lists the verified tags, commits, and digests.

## What is intentionally out of scope

The engineering deep dive, API reference, and Deployment & Operations are later documentation milestones. This user guide does not invent those pages. Complexity analysis exists in the source tree and is not an RC.8 user feature. Kubernetes Job execution and a trusted local-process path remain in the code as fallbacks; they are not the route RC.8 uses for Java submissions or Java Playground.
